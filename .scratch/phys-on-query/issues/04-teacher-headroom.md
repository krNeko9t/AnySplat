# 04 — 教师自己留了多少余量（同类别内标签方差）

Type: research
Status: open
Blocked by: 02

## Question

opus 测出的 **"类别解释 62.6%、残差 37.4%"** 用的是 **Infinigen 自带 shader**（客观标签）。
但实际训练用的是 **VLM 伪标签**。VLM 看单视角抠图，极有可能走"识别→木头→背标准数值"，
那样 `H(P_VLM | 类别) ≈ 0`，**残差在标签里根本不存在**，学生再强也学不出来。

**算法**：每条伪标签取 `(Factory类名, log10 E, log10 ν, log10 ρ)`，按类名分组，
对三个量各算 `组内方差 / 全体方差`。

- 比值 ≈ 0 ⇒ 教师在按类别查表，同类物体拿到一样的数。学生的天花板就是类别查表本身。
- 比值显著 > 0 ⇒ 教师真的在看图，学生有东西可学。

纯 CPU，几分钟。**不阻塞训练**——它测的是"上限有多高"，不是"能不能开训"。

顺带同时算出来的、直接能进论文的东西：
- 类别查表基线的数值本身（03 结果表里的一行，免费得到）
- 每个类别的实例数分布（用来判断按类别划分 train/val 是否可行）

**完成判据**：三个量的组内/全体方差比值，加一句结论："教师留了 X% 的类内余量"。

**02 顺手看到的两件事，会改变这票的结论怎么写：**

1. **最坏情形基本排除。** 肉眼可见类内方差不为零：同场景两张 `Bed` 一个 E=1.5 MPa/ρ=45（泡沫）、
   一个 E=8000 MPa/ρ=350（木头）；`Pillow` 跨 0.05/1/5 MPa；`room:wall` 跨 5 MPa/ρ=150 与 1e4 MPa/ρ=650。
   所以这票大概率不会得出 "H(P_VLM|类别) ≈ 0"。**但正因如此，光报一个比值不够了。**

2. **必须把"教师在看图"和"教师认错了东西"分开。** 实测有 `Towel` 拿到 E=1.1e4 MPa / ρ=650
   ——木头的数。同一个方差比值，两种解释意义完全相反：
   - 教师真在读图 ⇒ 学生有东西可学，余量是**信号**
   - 教师把 mask 对应错了物体 ⇒ 余量是**不可学的噪声**，学生最好的结果就是回归到类别均值

   **本票必须给出一个可判别的口径**，而不是只报比值。可用的免费抓手：每条标签都带
   `object_description`（一句话描述），把它和 Factory 类名比对，就能估出"描述与真实物体不符"的比例——
   `Towel` 那条的描述如果写的是柜子，就是 grounding 错误，不是物理判断。
   还带 `appearance_materials`（prototype + score）与 `physical_priors`（bin + confidence），也可交叉验。

3. 顺带：`n_views` 分布为 4/1/2/3 = 45530/3722/2294/1782。**只用了 1 个视角的 3,722 条**
   理应更不可靠，可以按 `n_views` 分层再算一遍方差比——若单视角那批方差明显更大，
   那部分余量就是噪声而非信号。
