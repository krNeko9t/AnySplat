# 04 — 教师自己留了多少余量（同类别内标签方差）

Type: research
Status: open
Blocked by: 02

## Question

opus 测出的 **"类别解释 62.6%、残差 37.4%"** 用的是 **Infinigen 自带 shader**（客观标签）。
但实际训练用的是 **VLM 伪标签**。VLM 看单视角抠图，极有可能走"识别→木头→背标准数值"，
那样 `H(P_VLM | 类别) ≈ 0`，**残差在标签里根本不存在**，学生再强也学不出来。

**算法**：每条伪标签取 `(Factory类名, log10 E, log10 ν, log10 ρ)`，按类名分组，
对三个量各算 `组内方差 / 全体方差`。

- 比值 ≈ 0 ⇒ 教师在按类别查表，同类物体拿到一样的数。学生的天花板就是类别查表本身。
- 比值显著 > 0 ⇒ 教师真的在看图，学生有东西可学。

纯 CPU，几分钟。**不阻塞训练**——它测的是"上限有多高"，不是"能不能开训"。

顺带同时算出来的、直接能进论文的东西：
- 类别查表基线的数值本身（03 结果表里的一行，免费得到）
- 每个类别的实例数分布（用来判断按类别划分 train/val 是否可行）

**完成判据**：三个量的组内/全体方差比值，加一句结论："教师留了 X% 的类内余量"。
