# 03 — "逼近上限"到底怎么量

Type: grilling
Status: open
Blocked by: —

## Question

目的地写的是"学生逼近教师"，但**没定义"逼近"是什么数**。不定义清楚，训练跑完了不知道成没成，
论文也没有主结论可报。

要定的：

1. **主指标**：学生 vs 教师标签的一致性用什么？Gaussian NLL（训练 loss 本身）不适合当报告指标。
   候选：三个量各自的 log10 MAE / ALDE / MnRE（已发表工作用的那几个，便于横向比）。
2. **参照系怎么摆**。至少三行：
   - 常数预测（全局均值）——地板
   - 类别查表（用训练集类别均值）——真正的对照
   - 学生模型
   教师本身不是一行数，因为学生的标签就是教师 ⇒ 教师的"误差"恒为 0。
   **所以"逼近上限"实际要报的是"学生 vs 类别查表"的相对位置**，而不是"学生 vs 教师"的距离。
   这一点要先想清楚再定指标。
3. **同时报的副指标**：mask mAP、几何 AbsRel——用来证明加物性没有把实例/几何搞塌。
4. **划分**：按场景划 train/val，还是按类别划？按类别划才能测"没见过的类别"，但会跟闭集 200 类打架。

**完成判据**：写下一张空的结果表骨架（行 = 方法，列 = 指标），训练一跑完就能往里填数。
