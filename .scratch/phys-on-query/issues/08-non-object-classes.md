# 08 — `room:*` / `Window` 这类非物体实例要不要进 phys loss

Type: grilling
Status: open
Blocked by: 04（**已于 2026-09-07 关闭 ⇒ 本票已解除阻塞**）

> 由本图 **Not yet specified** 的"数据清洗"一条毕业而来（[02 号票](02-labels-into-training.md)
> 把它量成了具体数字）。

## Question

[02 号票](02-labels-into-training.md)产出的类别表（51,981 实例 / 213 类）显示，**28.6% 的标签
落在不适合物理模拟的东西上**：

| 类 | 实例数 | 占比 |
|---|---|---|
| `Window` | 5,717 | 11.0% |
| `room:wall` | 3,361 | 6.5% |
| `room:floor` | 2,648 | 5.1% |
| `room:ceiling` | 1,950 | 3.8% |
| `room:exterior` | 1,175 | 2.3% |
| 合计 | **14,851** | **28.6%** |

（还没算 `PanelDoor`/`LiteDoor`/`LouverDoor` ≈ 2,386、`Mirror` 725、`WallArt` 1,055。）

墙/地板/天花板是房间的边界几何，不是可仿真物体；`Window` 有一半在 mask 里根本是 id=0 的背景
（02 §2）。它们还**天生占大像素**，在实例匹配里容易吃掉 query。

## 要决定的

1. 剔不剔？剔的话剔哪些（只 `room:*`？加 `Window`？加门/镜/挂画？）
2. **在哪一层剔**——三个位置语义完全不同：
   - 从 manifest / 类别表剔 ⇒ 分割 GT 也没了，模型不再学这些实例（改的是 03 的 mask mAP 口径）
   - 只从 `valid` LUT 剔 ⇒ 实例照学，只是不打物性 loss（**大概率是想要的那个**）
   - 只从评测指标剔 ⇒ 训练照旧，只是主表不含它们
3. 剔完训练分布怎么变：剩下 71.4% 的类别直方图会更长尾，[03 号票](03-approach-ceiling-metric.md)
   的"类别查表"基线数值会跟着变，**两票的数必须用同一个子集算**。
4. 反过来的论据：`room:wall` 的标签实测跨 5 MPa/ρ=150 到 1e4 MPa/ρ=650，
   说明教师对它们给的数并不退化。若 04 测出这批的类内方差和别的类一样"健康"，剔除就是白扔 28.6% 的监督。

**04 已出数（2026-09-07）**，直接答了本票第 4 点，且答案是**反向的**：

| 子集 | N | 描述一致率 | log10 E 类内方差占比 |
|---|---|---|---|
| 非物体类（`room:*` + Window/门/镜/挂画） | 19,118 | 51.1% | **95.6%** |
| 其余（真物体） | 32,863 | 50.5% | **65.9%** |

非物体类的类名几乎不解释任何方差，而两组 grounding 一致率相同 ⇒ **不是认错东西，
是教师对墙/地板/窗本来就给不出稳定的数。** 本票第 4 点的反向论据（"教师并不退化"）
在全量上不成立。

⚠️ 但 04 同时警告**别顺手扩大剔除范围**：按类内 sd 排序最脏的是**软体真物体**
（`Pillow` 2.00 / `Comforter` 1.99 / `Towel` 1.97 / `Blanket` 1.97 / `Mattress` 1.75 /
`Rug` 1.73，`room:floor` 1.43 才第 10）。软体归 [12 号票](12-label-reliability.md)，不归本票。

本票第 2 点（在哪一层剔）与 12 号票第 2 点同构，**两票的答案必须自洽**。

## 完成判据

一份明确的剔除清单 + 剔除发生在哪一层，且 03 的结果表骨架已按同一子集重述。
