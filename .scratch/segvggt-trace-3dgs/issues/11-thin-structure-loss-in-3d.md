## Question

view 02 上，芭比娃娃：**模型 2D 0.718 → 我们的 3D 0.595**。放大看
（`assets/04/02_gt_2d_3d.png`），丢的**不是随机的边界像素，是两侧的头发** ——
2D 已经漏了右侧一绺，3D 把两侧都漏了。猫头（GT 1）0.623 → 0.235 可能是同一个病，
也可能只是 GT 把猫拆成头/身而我们合成一个、被一对一 best-IoU 罚了（**先分清这两者**）。

薄 / 半透明结构在这条链路上有三个可能的失血点，本票要定位是哪个（或哪几个）：

1. **trace 侧**：头发的高斯被墙的高斯挡住或与之混合，`sum_gau_sem` 把两者平均，
   方向被拉向墙 ⇒ `q·f` 掉到 0 以下。（可查：头发区域高斯的 `num_ray` 和 logit 分布。）
2. **归一化侧**：`feat = sum_gau_sem / num_ray`。头发处每条光线的 αT 很小，
   但 `num_ray` 照常计数 ⇒ 分母不变分子小，方向不变但被压向噪声。
   **注意 04 已确认低 `num_ray` 的高斯认领得更少** —— 这条与那条读数是一致的，值得顺着查。
3. **阈值侧**：`logit > 0` 对薄结构过严。04 定这个阈值的依据是 2D 的判定边界压在 0，
   但那是**逐像素**的统计，薄结构在其中占比极小，边界位置不一定对它成立。
